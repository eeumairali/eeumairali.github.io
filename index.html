Research

Computer vision for precision livestock

Watching a herd by eye is slow, and changes in how an animal moves, eats or rests are often the first sign that something is wrong. My PhD uses cameras and deep learning to do this watching continuously: which animal is it, where has it been, and what is it doing?

  1. DetectFind every animal, and its face, in each video frame with one-stage detectors from the YOLO family. My first PhD paper fine-tunes YOLOv8 for cow faces.
  2. TrackKeep the same identity on each animal from frame to frame, combining detection with re-identification features.
  3. Recognise behaviourTurn each animal's track into behaviour – standing, lying, walking, feeding – for real-time monitoring.
  • Object detection
  • Multi-object tracking
  • Re-identification
  • Behaviour recognition
  • Deep learning
  • Real-time monitoring

Before the PhD, my MS research was in robotics: fusing several sensors with a neural network so an underwater robot can work out where it is.
