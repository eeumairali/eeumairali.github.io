# Umair Ali — personal research profile

The source of [eeumairali.github.io](https://eeumairali.github.io/): my academic profile as a PhD researcher in
Electrical Engineering at the University of Gujrat (Intelligent Systems Lab), working on computer vision for
precision livestock.

- `index.html` — the profile: research, publications, experience, education, teaching, skills, contact.
- `cv.html` — a printable CV; open it and use **Save as PDF** for an up-to-date PDF.
- `sw.js` — removes the offline cache the previous version of this site installed.

Both pages are plain HTML and CSS with no build step. To add a photo, save it as `assets/umair.jpg` and follow the
note next to the portrait in `index.html`.

For Python lessons and teaching, see [umaircodelab.com](https://umaircodelab.com).
